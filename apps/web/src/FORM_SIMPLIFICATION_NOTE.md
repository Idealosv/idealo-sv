# Simplificación de formularios

- Productos conserva Identificación y Precio visibles; Medidas y Producción se mantienen plegables mediante el gestor de secciones.
- Cotizaciones muestra primero cliente, estado, prioridad, proyecto y datos esenciales; parámetros comerciales, costos, medidas, descuentos y notas internas quedan detrás de controles “Más opciones”.
- Facturación mantiene el flujo diario visible y las herramientas administrativas de Hacienda cerradas por defecto.
- Ningún campo ni dato se elimina; solo cambia la exposición inicial para reducir saturación y errores de captura.
