# Flujo de facturación desde proyecto

- Al entrar a **Nueva factura**, el modo predeterminado es **Desde proyecto**.
- Cambiar entre proyecto y venta manual remonta la vista para evitar estado residual.
- Los botones activos de origen quedan visualmente diferenciados.
- El botón final para guardar/crear Crédito Fiscal usa el anaranjado institucional.
