# Catálogo de referencia · Súper Selectos

IDEALO BAR usa el catálogo público de Súper Selectos El Salvador únicamente como referencia de surtido y costo de compra.

- Fuente: https://www.superselectos.com/
- Consulta base: 2026-09-10
- Los precios pueden cambiar por sala, promoción y disponibilidad.
- El precio de Súper Selectos **nunca** se copia como precio de venta del bar.
- Los productos de referencia se identifican con las etiquetas `super-selectos` y `catalogo-referencia`.
- Los artículos de referencia no entran automáticamente a la Carta activa. El usuario debe seleccionarlos y definir su precio de venta.
- El catálogo de referencia se carga primero en `IDEALO BAR · PRÁCTICA`; no modifica la empresa real.

Categorías cubiertas: Cervezas, Smirnoff/RTD, Hard Seltzer, Vodka, Ron, Whisky, Tequila/Mezcal, Gin y licores, Aguardiente, Vinos, Espumantes y Sangrías.
