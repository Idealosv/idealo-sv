# Política de estabilidad CI

La validación continua debe seguir ejecutando pruebas API, auditorías de frontend, build y auditoría de dependencias en cada pull request hacia `main`.

Las pruebas estructurales añadidas en esta ronda convierten en reglas automáticas la unicidad futura de migraciones, el entrypoint autenticado del frontend y la presencia del recorrido empresarial completo dentro de la auditoría principal.
